# 教程扫描导入素材（docs/tutorial.md 配套）

本目录放了一组**可以“扫描导入”的素材图**（`fig_1.png` … `fig_5.png`），配套 [docs/tutorial.md](../tutorial.md) 第 7 节。

## 如何导入

1. 打开 Figure 工作台，进入任意工作区。
2. 点击顶部蓝色按钮 **📥 扫描导入**（`scanModal`）。
3. 在弹窗的文本框里粘贴本目录的完整路径：`J:\desk\模板和参考\figure show\figure_workspace\docs\tutorial_scans`。
4. 勾选导入，点击“导入”。

导入结果：

- 会建 5 个 Figure，Label 来自文件名（`fig_1` … `fig_5`），点击即进看板/抽屉；
- 每个 Figure 会把对应 `fig_N.png` 原图挂为源文件，也会自动当作预览。

> 如果文件名重复（已存在同名 Figure），导入会跳过并返回 `skipped`。
