## 二、已确认的问题

**label 改名会导致文件夹分裂**（2026-11-24 复现，在临时目录中验证，未触及真实数据）

1. 建 Figure 1，文件夹为 `Figure1`，上传 `a.xlsx`。
2. `PATCH` 把 label 改为 `Figure 9`，文件夹仍为 `Figure1`。
3. 再上传 `b.xlsx`，系统新建 `Figure9`，文件分裂。
4. 删除节点时只把 `Figure9` 移入 `.trash`，`Figure1/a.xlsx` 残留。

根源：所有路径都按当前 label 实时计算（`storage.figure_dir` / `panel_dir`），而 `PATCH` 接受 `label`。界面目前没有改名入口，但其他 agent 对接时会触发。详见阶段 B。**阶段 B 已改为持久化 `folder` 与同步改名（2026-11-24），以上保留为当时的复现记录。**
