# 入门教程：Figure 工作台

面向第一次用 Figure 工作台的你。以下从打开页面、建一张图、查看稿件样式为例，说明常见操作与概念。所有操作都在浏览器里完成，文件与数据库都留在本机。

## 1. 启动

- 在本仓库目录启动：`.bat` 或 `./run.sh`，再打开 `http://127.0.0.1:8000/`。
- 界面先看到「工作区列表」；第一次点「+ 新建论文工作区」。

## 2. 新建论文工作区

- 填 **code**（会成为数据根目录 `D:\ResearchData\{code}` 的名称），例如 `学术-实验`。
- 点「+ 新建论文工作区」后，进入该工作区看板。

## 3. 看板与新建 Figure

- 工作区顶部是 Figure 卡片，双击或点击打开详情抽屉。
- 点「+ 新建 Figure」，填写阶段式表单：
  - **图题**（结论句）、**图注（legend）**（逐面板说明、比例尺、样本量 n）；
  - **面板（子图）**，每行一个面板标签，如 `3A`；建图后自动创建为子图。
- 点击「OK / 创建」后，Figure 与面板目录一次创建好；如果中途失败会回滚。

## 4. 图片预览与溯源

- 看板卡片里的图像区域是当前版本的预览图。
- 详情抽屉里可以「贴/传预览图」、上传源文件（通常是 TIF/TIFF 等会自动转 PNG）；
- 点图可在抽屉里查看来源文件名、相对路径与 SHA-256（溯源全链）。

## 5. 面板（子图）

- 在抽屉「面板（子图）」列表里点一个子图；打开子图抽屉可上传源文件与预览图；
- **面板的预览图落在它自己的目录里**（如 `Figure1/A/preview.png`），父 Figure 的文件数会自动统计子图文件；
- 在期刊视图里，面板会按子图展示（标号 a/b/c + 预览图），而不是只有文字。

## 6. 状态与工作流

- 每个 Figure / 子图都可按 **状态**：候选 / 采用 / 弃用 / 待重做。
- 可按 **重要度**：关键 / 一般 / 辅助，关键图会明显标注 ★；
- 标签可用于跨图检索；备注区存决策日志（如“采用时间 + 依据”）。

## 7. 扫描导入（可选）

- 指向已有文件夹 → 只读发现图片 → 勾选导入为 Figure（原图留档，同名 Figure 会跳过）。

## 8. 期刊视图

- 在工作区顶部点「📰 期刊视图」，工作区排成稿件样式（衬线体、单栏、图注、状态标记），便于核对与打印。
- 点击稿件中的图片或文字会跳到该 Figure 抽屉。

## 9. 检索与导出

- 顶部搜索框可按标签 / 文件名 / 样本 / 工作区名全局检索；
- 「导出」功能基于「已采用」的节点（`SourceData` / 图注草稿 / 数据可得性）。

## 10. 数据跨机迁移（可选）

- 换电脑时额外拷贝 `data/fw.db` 与整个 `D:\ResearchData` 树；数据库只存索引，文件系统是真源。
